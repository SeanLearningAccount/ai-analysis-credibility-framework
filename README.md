# AI 分析可信度评估框架

本仓库为一份示例分析的辅助材料，用于展示：  
**在证据受限的情况下，如何评估 AI 生成分析结论的可信度，并判断哪些结论可以进入决策，哪些必须降级为假设。**

---

## 这个仓库解决什么问题

在实际分析与投资研究中，AI 模型可以快速生成看似合理的判断，但常见风险包括：

- 证据不足却给出确定性结论  
- 将相关性误写为因果关系  
- 用局部样本推断整体结构  
- 给出无法被验证或反证的策略判断  

本仓库展示了一种更克制的分析方式：  
**先判断“能不能下结论”，再讨论“结论是什么”。**

---

## 仓库内容说明

本仓库包含以下辅助材料，用于支撑主文档中的分析过程：

- **Notebook**  
  用于从公开数据集中生成 Evidence Pack 及基础切片（如 overall、weekly、channel、source/medium、device、country 等）。

- **Evidence Summary**  
  对证据单元的结构化说明，包括每类证据的口径、范围与限制。

- **Scorecard**  
  用于评估结论可信度的轻量评分表，关注证据对齐、不确定性、因果风险与稳定性。

以上材料用于补充理解分析过程，但不构成主结论本身。
